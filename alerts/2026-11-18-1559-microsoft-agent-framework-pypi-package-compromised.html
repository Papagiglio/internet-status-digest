Microsoft Agent Framework PyPI package compromised with credential stealer

Malicious versions 1.26.1 and 1.26.2 of Microsoft's agent-framework PyPI package (about 200,000 monthly downloads) were published Nov 17 to steal Azure, AWS, GitHub and other cloud credentials from developer systems (Global; Microsoft is HQ'd in Redmond, US).
