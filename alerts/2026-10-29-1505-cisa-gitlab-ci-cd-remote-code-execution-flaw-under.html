CISA: GitLab CI/CD remote code execution flaw under active exploitation

CISA added GitLab CE/EE CVE-2026-97229, an integer overflow in CI/CD regex handling that can let an unauthenticated attacker run code on the GitLab server, to its exploited-vulnerabilities catalog on Oct 29 with a Nov 1 patch deadline.
